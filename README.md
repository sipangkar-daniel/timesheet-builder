# ⏱️ Timesheet Builder

A modern, lightweight, and pixel-perfect **Timesheet & Overtime Generator** built for structured reporting, including workday configuration, overtime tracking, and PDF export in a clean Mandiri-style format.

🔗 Live App: https://timesheet-builder-dusky.vercel.app/

## 🚀 Features

- 📅 Month & Year Timesheet Builder
- 🧠 Smart default activity generation
- ⏱️ Baseline hours per business day
- 🏖️ Weekend, holiday, and leave day selection
- 📊 Overtime detail auto-generation
- 📄 Export to PDF (A4 format)
- 📥 Import JIRA CSV / JSON (if enabled)
- 🖊️ Optional signature & company logo support
- 🔍 Zoom In / Zoom Out / Reset (100%) for better preview control
- 🔀 Merge & Unmerge table cells (live preview support)
- ⚡ Fast, responsive UI
